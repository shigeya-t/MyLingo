プライバシーポリシー

最終更新日: 2026年10月10日

このポリシーは、Chrome拡張機能「MyLingo Page Translator」と MyLingo のWebアプリが利用者のデータをどう扱うかを説明するものです。MyLingo は独自のサーバーを持たず、開発者が利用者のデータを受け取ったり、収集・保存したりすることはありません。

  • 文章は、翻訳を指示したときにだけ、利用者が選んだAIサービス（OpenAI・Anthropic・Google）へ送信されます。
  • APIキーと設定はブラウザ内にだけ保存されます。APIキーはパスキーまたはパスフレーズで暗号化できます。
  • アクセス解析・トラッキング・広告はありません。データを販売したり、ほかの第三者へ渡したりすることもありません。

扱うデータ

  • Webサイトのコンテンツ: 翻訳するページの文章、または選択して右クリックメニューから翻訳する文章。翻訳を始めたとき（ツールバーのポップアップ、右クリックメニュー、キーボードショートカット）にだけ読み取ります。
  • APIキー: 利用者が入力した OpenAI・Anthropic・Google Gemini のAPIキー。
  • 設定: 選択中のサービス、モデル名、翻訳先の言語、翻訳モード、リクエスト数の上限、表示言語。

閲覧履歴、個人情報、位置情報などそのほかのデータは収集しません。

データの送信先

翻訳するとき、翻訳する文章は利用者自身のAPIキーを使って、ブラウザから選択したサービスへ直接送信されます。

  • ChatGPT: OpenAI（api.openai.com）— OpenAI のプライバシーポリシー
  • Claude: Anthropic（api.anthropic.com）— Anthropic のプライバシーポリシー
  • Gemini: Google（generativelanguage.googleapis.com）— Google のプライバシーポリシー、Gemini API 利用規約

送信した文章がそのサービスでどう扱われるか（保存期間や学習への利用など）は、各サービスの規約と利用者のアカウント設定によります。機密性の高い文章を翻訳する前にご確認ください。MyLingo がこれ以外の送信先へデータを送ることはありません。

保存

  • 拡張機能は、APIキーと設定を端末内の chrome.storage.local に保存します。Google アカウントには同期されません。
  • APIキーの暗号化を有効にすると、キーは暗号化された形（AES-GCM）でだけ保存されます。ロックを解除したあと、復号したキーはブラウザを閉じるまでメモリ上（chrome.storage.session）に保持されます。
  • 翻訳結果は保存しません。ページ上に表示し、原文に戻したときやページを離れたときに破棄されます。
  • Webアプリは、同じ種類の設定をブラウザの localStorage に保存します。

権限

  • activeTab・scripting: 翻訳するタブの文章を読み取り、翻訳文に差し替えるため。そのタブで翻訳を指示したときにだけ使います。
  • storage: APIキーと設定を端末内に保存するため。
  • contextMenus: 右クリックメニューに「MyLingo で翻訳」を追加するため。
  • api.openai.com・api.anthropic.com・generativelanguage.googleapis.com へのアクセス: 選択したサービスへ翻訳のリクエストを送るため。

データの利用目的

データは、MyLingo の唯一の目的である翻訳のためにだけ使います。販売、選択したAIサービス以外の第三者への提供、広告への利用、信用力の判断や融資目的での利用は行いません。Chrome の API から得た情報の利用は、限定利用（Limited Use）の要件を含む Chrome ウェブストアのユーザーデータに関するポリシーに従います。

データの削除

拡張機能の設定画面でAPIキーを消すか、chrome://extensions から拡張機能を削除してください。削除すると、拡張機能が保存したデータはすべて消去されます。Webアプリの場合は、ブラウザでそのアドレスのサイトデータを削除してください。AIサービス側に残るデータの削除は、各サービスのアカウント設定から行ってください。

子どもについて

MyLingo は子ども向けのサービスではなく、子どもの情報を意図して収集することはありません。
